# Vittorio Emanuele — Menu digitale

Rigenerazione basata sul sito ufficiale, sui PDF del menu e sul logo/immagine forniti.

## Identità visiva

- Fondo blu petrolio e pannelli crema.
- Palette blu ceramica, corallo e giallo senape.
- Fasce geometriche ispirate alle maioliche siciliane.
- Logo/monogramma inserito nell’header come elemento di riconoscibilità.
- Tipografia editoriale con titoli serif e navigazione compatta.

## File

- `index.html` — pagina del menu e informazioni del locale
- `style.css` — stile responsive e navigazione fissa
- `menu.json` — dati strutturati del menu e del locale
