# Vittorio Emanuele — Menu digitale

Menu aggiornato con tutte le proposte del PDF `Menu-Vitt-Emanuele.pdf`.

## Categorie

- Sfiziosità
- Antipasti
- Primi piatti
- Secondi piatti
- Pizzeria — Classiche
- Insalatone
- Dolci

Il menu pizzeria precedente è stato mantenuto e le proposte del ristorante sono state aggiunte in sezioni separate.

## File

- `index.html` — pagina del menu e informazioni del locale
- `style.css` — stile responsive, identità siciliana e navigazione fissa
- `menu.json` — dati strutturati del menu

## Note

Gli asterischi sono mantenuti come nel PDF. Per allergeni, ingredienti, preparazioni e disponibilità chiedere conferma al personale. La fascia di spesa indicativa proveniente da Google Maps non è stata inserita.
