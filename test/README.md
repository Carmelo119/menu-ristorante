# Vittorio Emanuele — Menu digitale

Il design è stato aggiornato usando l’immagine reale `images/identita-siciliana.jpg` come elemento principale dell’hero e come dettaglio decorativo nelle sezioni. La composizione riprende l’impostazione editoriale del sito ufficiale: grande tipografia serif, fondo blu profondo, blocchi crema, spaziatura ampia e navigazione compatta.

## File

- `index.html` — pagina del menu con immagine maiolica reale
- `style.css` — layout editoriale e responsive
- `menu.json` — dati strutturati del menu
- `images/identita-siciliana.jpg` — immagine decorativa del locale

Il menu e i dati del locale restano invariati. La fascia di spesa Google Maps non è inclusa.
