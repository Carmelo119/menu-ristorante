# Vita Cucina Paesana — Menu digitale

Pagina menu responsive realizzata a partire dal PDF `vita_cucina_paesana.pdf`.

## Struttura

- `index.html` — pagina HTML del menu
- `style.css` — stile responsive e accessibile
- `menu.json` — dati strutturati del menu

## Dati non inclusi

Indirizzo, telefono, orari e link Google Maps non sono stati inseriti perché non verificabili dal materiale disponibile.

Il menu riporta la versione **Giugno**, gli allergeni indicati nel documento e il costo di servizio e coperto di **€ 1,20**.
